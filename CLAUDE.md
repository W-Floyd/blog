# CLAUDE.md

## Authorship marking

Prefix every prose line you generate in post content with `***(CLAUDE)***`.
This marks AI-written prose so it's distinguishable from the author's own.

- Applies to prose sentences/paragraphs in post bodies (e.g. `content/posts/**/index.md`).
- Does NOT apply to: front matter, headings, code, shortcodes (`{{< … >}}`),
  HTML comments/TODOs, alt text, or any non-prose markup.
- Leave existing prose the author wrote untouched.
